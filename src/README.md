#  Прогнозирование надежности б/у автомобилей (Kaggle: Don't Get Kicked)

##  Описание проекта
Этот проект посвящен задаче бинарной классификации: прогнозированию того, окажется ли б/у автомобиль, купленный на аукционе, «кидаловом» (некачественной машиной, приносящей убытки). 
* **Целевая переменная:** `IsBadBuy` (1 — плохая покупка, 0 — хорошая).
* **Метрика качества:** Gini / ROC-AUC.

---

##  Инструкция по запуску и настройке

### 1. Клонирование репозитория и окружение
```bash
git clone https://github.com
cd твой_репозиторий
python3 -m venv .venv
source .venv/bin/activate  # Для WSL/Linux
pip install -r requirements.txt
```

### 2. Настройка Kaggle API для загрузки данных
Для автоматического скачивания датасета проекта используется официальный Kaggle API. Так как персональные токены доступа нельзя выкладывать в публичный репозиторий, перед запуском скрипта выполните настройку на своем компьютере:

1. Зарегистрируйтесь на [Kaggle](https://kaggle.com) и примите правила соревнования на странице [Don't Get Kicked](https://kaggle.comc/DontGetKicked) (нажмите **Join Competition** во вкладке Data).
2. Перейдите в настройки своего профиля `Kaggle -> Settings -> API` и нажмите **Create New Token**. На экране появится ваш личный ключ (`API Token`).
3. Сохраните полученный токен в вашу систему. 

**Для пользователей Linux / WSL (Ubuntu):**
Выполните одну команду в терминале, подставив вместо `ВАШ_ТОКЕН` значение с сайта Kaggle:
```bash
mkdir -p ~/.kaggle && echo "ВАШ_ТОКЕН" > ~/.kaggle/access_token && chmod 600 ~/.kaggle/access_token
```

**Для пользователей Windows (PowerShell):**
Создайте папку `.kaggle` в директории пользователя и сохраните ключ в файл `access_token` без расширения:
```powershell
New-Item -ItemType Directory -Force -Path "\$HOME\.kaggle"
"ВАШ_ТОКЕН" | Out-File -FilePath "\$HOME\.kaggle\access_token" -Encoding ascii
```

### 3. Загрузка датасета
После настройки токена запустите скрипт для автоматического скачивания и распаковки данных:
```bash
python3 src/download_competition_data.py
```
Данные скачаются в папку `./data/` в корне проекта.
